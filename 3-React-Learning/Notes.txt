If we define the Footer component with a lowercase first letter, it will be treated as a regular HTML element and will not work as expected. By following this convention and defining the Footer component with an uppercase first letter, we ensure that it is recognized as a React component and can be used correctly in our application.

    - 6) Default Prop Values
            - Sometimes, you'll build components that may receive an optional prop. For example, a custom Button component may receive a type prop.
            - So the Button component should be usable either with a type being set:
            - EX:-
            <Button type="submit" caption="My Button" />
            Or without it:

            <Button caption="My Button" />
            To make this component work, you might want to set a default value for the type prop - in case it's not passed.

            This can easily be achieved since JavaScript supports default values when using object destructuring:

            export default function Button({ caption, type = "submit" }) { 
            // caption has no default value, type has a default value of "submit"
            }

            - Notes:
                Children:
                    Props are used to pass specific data to a component.
                    Children are used to pass JSX or content inside the component tags.
                    Props are written as attributes in the opening tag.
                    Children are written between the opening and closing tags.
                    Props usually pass values like text, numbers, or functions.
                    Children can pass full HTML or JSX elements.
                    Props make components customizable.
                    Children make components more flexible and reusable.
                Attribute:
                    Custom attributes are user-defined props passed to a component.
                    They allow components to receive dynamic data.
                    Custom attributes are written inside the component tag.
                    They help make components reusable and configurable.
                    A component can receive multiple custom attributes.
                    Common examples are title, name, price, or onClick.
                    Custom attributes are accessed using props inside the component.

                import React from 'react';

                export default function App() {
                    const [showMessage, setShowMessage] = React.useState(false);

                    function showMessageHandler() {
                        setShowMessage(true);
                    }

                    function hideMessageHandler() {
                        setShowMessage(false);
                    }

                    return (
                        <div>
                            {showMessage ? (
                                <div id="message">
                                    <h2>Hello!</h2>
                                    <p>Welcome to our React application.</p>
                                    <button onClick={hideMessageHandler}>Close</button>
                                </div>
                            ) : null}

                            <button onClick={showMessageHandler}>
                                Show Message
                            </button>
                        </div>
                    );
                }
