            - that renders a paragraph with the text "My Footer", while the App component is responsible for rendering the main content of the application.
            - It is used in the App component to display a footer message.
            - is defined as a function that returns a JSX element.
            - It can be reused in different parts of the application if needed, and it helps to keep the code organized by separating concerns.
            - we should write the Footer component before the App component because the App component uses the Footer component.
            - We can also write the Footer component in a separate file and import it into the App component, which is a common practice in larger applications to keep the code organized and maintainable.
            - In this example, we have defined the Footer component in the same file for simplicity, but in a real application, it would be better to separate it into its own file and import it into the App component.
            - we should write the footer component with uppercase because in React, 
                - components must be defined with an uppercase first letter. 
                - This is a convention that helps to distinguish components from regular HTML elements. If we define the Footer component with a lowercase first letter, it will be treated as a regular HTML element and will not work as expected. By following this convention and defining the Footer component with an uppercase first letter, we ensure that it is recognized as a React component and can be used correctly in our application.

    - 6) Default Prop Values
            - Sometimes, you'll build components that may receive an optional prop. For example, a custom Button component may receive a type prop.
            - So the Button component should be usable either with a type being set:
            - EX:-
            <Button type="submit" caption="My Button" />
            Or without it:

            <Button caption="My Button" />
            To make this component work, you might want to set a default value for the type prop - in case it's not passed.

            This can easily be achieved since JavaScript supports default values when using object destructuring:

            export default function Button({ caption, type = "submit" }) { 
            // caption has no default value, type has a default value of "submit"
            }

            - Notes:
                Children:
                    Props are used to pass specific data to a component.
                    Children are used to pass JSX or content inside the component tags.
                    Props are written as attributes in the opening tag.
                    Children are written between the opening and closing tags.
                    Props usually pass values like text, numbers, or functions.
                    Children can pass full HTML or JSX elements.
                    Props make components customizable.
                    Children make components more flexible and reusable.
                Attribute:
                    Custom attributes are user-defined props passed to a component.
                    They allow components to receive dynamic data.
                    Custom attributes are written inside the component tag.
                    They help make components reusable and configurable.
                    A component can receive multiple custom attributes.
                    Common examples are title, name, price, or onClick.
                    Custom attributes are accessed using props inside the component.

    - 14) Summary
        React Essentials — English
            1. Components
                React is built around Components.
                A Component is a function.
                Its name must start with an uppercase letter.
                It must return something React can render, usually JSX.
                Components can be used like custom HTML elements inside JSX.
            2. Props
                Props are used to pass data to Components.
                Props are received as the first parameter of the Component function.
                We can use object destructuring to access props easily.
                We can also pass an entire object using the spread operator.
            3. Dynamic Content
                We use {} inside JSX to display dynamic content.
                They can be used between tags or inside attributes.
            4. children
                children is a special prop provided by React.
                It contains the content placed between the opening and closing tags of a Component.
                Example:
                    <Todo>Learn React</Todo>
                    Learn React is received through children.

            5. Events
                React can listen to events using event props such as onClick.
                We can also create custom props such as onSelect.
                Custom event props can be used to pass functions between Components.
                6. useState
                useState is used to manage changing data.
                When the state changes, React executes the Component again.
                React reevaluates the JSX.
                It compares the old result with the new result.
                Then it updates the UI where changes are needed.
            7. Conditional Rendering
                We can display different content depending on a condition using:
                    - if statements
                    - Ternary operator ? :
                    - Logical AND &&
            8. Rendering Lists
                We use map() to convert an array of data into JSX elements.
                todos.map(todo => <Todo>{todo}</Todo>)
                Each item should have a unique key so React can efficiently track and update the list.
                Key Idea

            Components → JSX → Props → children → Events → State → Conditional Rendering → Lists & Keys

        أساسيات React — عربي
            1. الـ Components
                React بيعتمد بشكل أساسي على Components.
                الـ Component عبارة عن function.
                اسمها لازم يبدأ بحرف Capital.
                لازم ترجع حاجة React يقدر يعرضها، وغالبًا بتكون JSX.
                نقدر نستخدم الـ Components داخل JSX كأنها HTML elements مخصصة.
            2. الـ Props
                الـ Props بنستخدمها عشان نمرر بيانات للـ Components.
                الـ Props بتوصل للـ Component كأول parameter في الـ function.
                نقدر نستخدم object destructuring للوصول للـ props بسهولة.
                ونقدر كمان نمرر object كامل باستخدام spread operator.
            3. الـ Dynamic Content
                بنستخدم {} داخل JSX لعرض محتوى ديناميكي.
                ممكن نستخدمها بين الـ tags أو داخل الـ attributes.
            4. الـ children
                children هو special prop بيوفره React.
                بيحتوي على المحتوى الموجود بين opening و closing tags للـ Component.

                مثال:
                <Todo>Learn React</Todo>
                هنا:
                Learn React
                بتوصل للـ Todo عن طريق children.

            5. الـ Events
                React يقدر يسمع للأحداث باستخدام event props زي onClick.
                ونقدر نعمل props خاصة بينا زي onSelect.
                الـ custom event props بتساعدنا نمرر functions بين الـ Components.
            6. useState
                useState بنستخدمه لإدارة البيانات اللي ممكن تتغير.
                لما الـ state تتغير، React يعيد تنفيذ الـ Component.
                React يعيد تقييم الـ JSX.
                يقارن النتيجة القديمة بالجديدة.
                وبعدها يحدث الـ UI في الأماكن اللي حصل فيها تغيير.
            7. Conditional Rendering
                نقدر نعرض محتوى مختلف حسب condition باستخدام:
                    if
                    Ternary operator ? :
                    Logical AND &&
            8. Rendering Lists
                بنستخدم map() لتحويل الـ array إلى عناصر JSX.
                todos.map(todo => <Todo>{todo}</Todo>)
                لازم كل عنصر يكون له key مميز عشان React يقدر يتابع العناصر ويحدث الـ list بكفاءة.
                الخلاصة
                Components → JSX → Props → children → Events → State → Conditional Rendering → Lists & Keys
