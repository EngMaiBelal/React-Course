            - that renders a paragraph with the text "My Footer", while the App component is responsible for rendering the main content of the application.
            - It is used in the App component to display a footer message.
            - is defined as a function that returns a JSX element.
            - It can be reused in different parts of the application if needed, and it helps to keep the code organized by separating concerns.
            - we should write the Footer component before the App component because the App component uses the Footer component.
            - We can also write the Footer component in a separate file and import it into the App component, which is a common practice in larger applications to keep the code organized and maintainable.
            - In this example, we have defined the Footer component in the same file for simplicity, but in a real application, it would be better to separate it into its own file and import it into the App component.
            - we should write the footer component with uppercase because in React, 
                - components must be defined with an uppercase first letter. 
                - This is a convention that helps to distinguish components from regular HTML elements. If we define the Footer component with a lowercase first letter, it will be treated as a regular HTML element and will not work as expected. By following this convention and defining the Footer component with an uppercase first letter, we ensure that it is recognized as a React component and can be used correctly in our application.

                    => Notes:-
                        1- Object Destructuring (in function parameters)
                            Extracts values directly from an object (like props)
                            Makes code shorter and cleaner
                            Improves readability (no need for props.title)
                            Avoids repetitive props. usage
                            Common and recommended pattern in React
                            Instead of props.title → use title directly 
                                {name of properties, ---, ---} instead of props
                            Easier to read and maintain
                        2- Rest Property (in function parameters)
                            function Cards({ ...concept })
                            It collects all incoming props into a single object called concept
                            It “groups all props into one object”

                            ... is called the spread operator
                            It spreads (expands) an object’s properties
                            Used to pass all object values as props
                            {...cardComponents} = pass all properties inside the object
                            Same as writing each prop manually
                            In React Makes code shorter, cleaner and Very useful with map()

                                <Component {...item} />

                                cardPhoto={item.cardPhoto}
                        - Important
                            Object keys must match prop names
                            item.title → props.title 
                        - Core idea
                            Object → spread (...) → props → component

                - map in React (Summary)
                    map loops through each item in an array
                    Each item in the data becomes a separate component
                    item represents the current object in each loop
                    We use item.title, item.description, item.cardPhoto to access data
                - In React
                    map is used to render lists (like cards)
                    It converts data into UI components
                - key
                    Every item in a map must have a key
                    React uses it to identify and update elements efficiently
                    Best practice: use a unique id, otherwise use index (temporary)
                - Core idea
                    Data → map → Components → UI


    - 6) Default Prop Values
            - Sometimes, you'll build components that may receive an optional prop. For example, a custom Button component may receive a type prop.
            - So the Button component should be usable either with a type being set:
            - EX:-
            <Button type="submit" caption="My Button" />
            Or without it:

            <Button caption="My Button" />
            To make this component work, you might want to set a default value for the type prop - in case it's not passed.

            This can easily be achieved since JavaScript supports default values when using object destructuring:

            export default function Button({ caption, type = "submit" }) { 
            // caption has no default value, type has a default value of "submit"
            }
    - 7) Render a List Using map()
            Create a React component called TaskItem that displays a title and a description.
            Requirements:
                Create your own array of objects (at least 2 items)
                Each object must contain: id, title, and description
                Use map() to render all items
                Each item should be displayed inside an <li>
                Add a unique key for each item
            Important:
                The first object must have:
                Title: "Learn JavaScript"
                Description: "Understand basics like variables and functions"
                These values must appear on the page
            - Solution
                function TaskItem({ title, description }) {
                      return (    
                        <li>      
                      <h2>{title}</h2>      
                      <p>{description}</p>    
                      </li>  
                    );
                }
                const tasks = [  
                    {    
                        id: 1,    
                        title: "Learn JavaScript",    
                        description: "Understand basics like variables and functions"  
                    },  {    
                        id: 2,    
                        title: "Learn React",    
                        description: "Build components and manage state"  
                    }
                ];
                function App() {  
                    return (    
                    <div>      
                        <h1>My Tasks</h1>      
                            <ul>        
                                {tasks.map((task) => (
                                    <TaskItem
                                    key={task.id}
                                    title={task.title}
                                    description={task.description}
                                    />        
                                ))}      
                            </ul>    
                        </div>  
                                            
                    );
                }
                export default App;
